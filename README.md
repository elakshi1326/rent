# Rentease — India Rental Website Template

A free-to-customize, responsive front-end starter for a flat and apartment rental website in India. Built with plain HTML, CSS, and JavaScript. No framework or build step is required.

Developed by Elakshi Sood.

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and use the Live Server extension.
3. Internet is needed for Google Fonts and the remote sample property photos from Pexels.

## Customize
- **Brand name and page content:** `index.html`
- **Colors, fonts, spacing, layout:** `style.css` (edit the CSS variables near the top)
- **Sample homes, city/rent/BHK filters, saved favourites:** `script.js`
- Replace the example listings and photos with accurate property details and images you have permission to use.
- Change `hello@example.com` to your own email address.

## Included
- Responsive homepage design
- Dark lavender and plum theme with saffron accents, a subtle animated background, and reduced-motion support
- Time-of-day welcome message with the current local date and a daily quote
- Rental-help chatbot with common answers and chat-based city, budget, BHK, furnishing, and property-type filters
- Feedback form for reviews, comments, and suggestions (opens an email draft; submissions are not stored by the site)
- Search by city, maximum monthly rent, and BHK
- Sample Himachal Pradesh apartment and PG/shared-room options in Shimla, Dharamshala, Solan, Manali, and Mandi
- Furnished/unfurnished filters
- Rental listing cards with monthly prices and property facts
- Save/favourite buttons stored in the visitor's browser
- Mobile-friendly layout
- “List your property” email link

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment URL shown on the Pages settings screen.

## Important limitations
This is a **front-end demo**, not a complete rental marketplace backend. Sample listings are illustrative and are not verified available properties. Search, favourites, and the scripted rental-help chatbot run in the browser; the chatbot is not connected to an AI service and cannot verify listings. Feedback and list-property actions open an email draft; feedback is not stored by the site. Accounts, landlord verification, database storage, and real listing submissions need a backend or connected service before real-world use.
