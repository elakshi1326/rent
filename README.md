# Rentease — India Rental Website Template

A free-to-customize, responsive front-end starter for a flat and apartment rental website in India. Built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Preview locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and use the Live Server extension.
3. Internet is needed for Google Fonts and the remote sample property photos.

## Customize
- **Brand name and page content:** `index.html`
- **Colors, fonts, spacing, layout:** `style.css` (edit the CSS variables near the top)
- **Sample homes, city/rent/BHK filters, saved favourites:** `script.js`
- Replace the example listings and photos with accurate property details and images you have permission to use.
- Change `hello@example.com` to your own email address.

## Included
- Responsive homepage design
- Search by city, maximum monthly rent, and BHK
- Furnished/unfurnished filters
- Rental listing cards with monthly prices and property facts
- Save/favourite buttons stored in the visitor's browser
- Mobile-friendly layout
- “List your property” email link

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the deployment URL shown on the Pages settings screen.

## Important limitations
This is a **front-end demo**, not a complete rental marketplace backend. Sample listings are illustrative and are not verified available properties. Search and favourites run in the browser. The contact/list-property links open an email draft; forms, accounts, landlord verification, database storage, and real listing submissions need a backend or connected service before real-world use.
